# 11. Design direction

## Overall direction

Create a modern Kampala restaurant website that combines:

- dark sophisticated surfaces
- warm wood tones
- restrained blue accent lighting
- warm food photography
- strong typography
- clean spacing
- subtle texture
- real restaurant atmosphere

The blue should be an **accent**, not a blanket background for the whole website.

Use warm neutrals and charcoal to prevent the site from looking like a generic blue restaurant template.

## Important balance

The real restaurant has strong visual elements:
- blue LEDs
- wood
- black surfaces
- red brick
- greenery
- warm amber lighting

The website should organize these elements into a coherent visual system rather than reproducing the interior literally.

# 17. Image-generation workflow

When the developer requests a food image:

1. Check the menu source.
2. Confirm the exact menu item and description.
3. Check the local `food` image folder first.
4. If an adequate existing image already covers the item, report that **no new image is needed**.
5. If no suitable image exists, prepare a dedicated image-generation prompt for that exact item.
6. Keep photography consistent across dishes.
7. Use realistic restaurant photography rather than advertising composites.
8. Avoid text, logos, prices or menu labels inside generated food photographs unless explicitly requested.
9. Label generated files clearly and consistently.

Suggested naming format:

`drift-dine-[category]-[item].webp`

Examples:

- `drift-dine-beef-beef-steak.webp`
- `drift-dine-beef-beef-curry.webp`
- `drift-dine-pilau-chicken-pilau.webp`
- `drift-dine-wraps-chicken-wrap.webp`
- `drift-dine-pizza-beef-pizza.webp`
